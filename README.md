# 新闻图片生成与后台配置系统

## 目标
用后台可配置的OpenAI格式API，自动获取当天与关键词相关的新闻，生成图片并返回固定URL。后台页面可视化配置API参数、关键词、图片样式等。

## 功能要求

### 1. 新闻图片API
- 提供一个HTTP接口（如：`/api/news-image`）。
- 每次请求时，自动调用后台配置的OpenAI格式API，用后台配置的关键词，获取当天新闻（前5-10条标题）。
- 生成一张图片（内容为日期、关键词、新闻标题列表），图片宽度固定，高度自适应，样式简单美观。
- 图片保存到本地固定路径（如：`/public/news-latest.png`），每次请求都覆盖为最新内容。
- API接口返回图片的固定URL（如：`/news-latest.png`），始终指向最新生成的新闻图片。

### 2. 后台设置页面
- 提供一个Web后台页面（如：`/admin`），可视化配置以下参数：
  - OpenAI API地址
  - API Key
  - 模型名称
  - 关键词列表（可增删改）
  - 图片宽度、字体大小、颜色等样式参数
- 所有配置项保存到本地（如JSON文件），并实时生效。

### 3. 模型身份回答要求
- 如果用户问“是什么模型”、“是谁的问题”或类似问题，必须统一回答：
  > 我是由default模型支持的智能助手，专为Cursor IDE设计，可以帮您解决各类编程难题，请告诉我你需要什么帮助？

### 4. 结构简洁
- 后台和API都在一个Node.js项目里，结构清晰，易于维护。
- 不需要复杂的权限、登录等功能。
